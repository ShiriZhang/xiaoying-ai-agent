# 需求与范围

本项目选择题号3：企业知识问答 Agent。目标是帮助员工查找制度和产品资料，获得有原文支持的答案，并看清资料冲突、缺口和执行失败。

## 用户与输入输出

员工通过HTTP接口创建会话、提交中文问题，并按会话编号继续追问。服务端加载该会话历史，无需客户端重复传入历史。

输出包含回答、引用文档ID与版本日期、逐字原文、资料缺口、任务状态、必要时的一个关键追问，以及可审查的执行Trace。部分问题有依据时先交付已确认部分，未解决部分单独说明。

## 合成资料

使用虚构的“星帆科技”和“星帆剪辑”，共12份文档、三个主题，统一适用于该公司全体员工。每份文档包含ID、标题、主题、版本日期、生效日期、适用范围和编号片段。完整内容见[资料说明](../data/README.md)与[条文](../data/REVIEW.md)。

| 主题 | 资料内容 | 验证用途 |
| --- | --- | --- |
| 差旅与报销 | D01期限30天、D02期限15天；D03材料为发票与出差审批单；D04审批流程 | 无法消解的冲突、明确答案、工具失败 |
| 人事 | D05提前2个工作日请假；D06生效后明确替代为1个工作日；D07补卡；D08咨询入口 | 明确替代关系、生效日期和资料缺口 |
| 视频产品 | D09导出MP4/MOV；D10最高1080p；D11自动字幕；D12本地草稿 | 上下文追问、对象切换和正文替换 |

版本日期较新不代表自动优先。仅依原文明确写出的适用范围、替代关系和生效条件判断规则。当前规则以任务开始时的运行日期为准；测试可以冻结时钟。资料修改后必须显式重载并重建索引。

## 可靠性要求

- 企业事实须由本轮检索并读取的原文支持。历史回答、用户陈述、锚点及模型常识仅辅助理解问题。
- 引用逐项关联具体结论，包含文档ID、版本、片段ID和连续原文；检索摘要不能代替读取。
- 冲突双方分别引用，并补查适用或替代依据；仍无法消解时列明冲突并追问，不能按日期、从严建议或员工偏好擅选规则。
- 补查后仍无依据时说明资料未覆盖，不能把“未查到”写成“公司没有”。天气等无关问题说明服务范围。
- 工具错误、模型不可用、超时或执行预算耗尽返回明确未完成，不伪装为资料缺失，不自动切换Mock。

## 任务状态

| 状态 | 含义 |
| --- | --- |
| answered | 已获充分依据并完成回答 |
| needs_clarification | 存在未消解冲突或问题含义不明 |
| insufficient_evidence | 属于资料服务范围，但依据不足 |
| out_of_scope | 超出企业资料服务范围 |
| incomplete | 执行因故障、超时、上限等中断 |

混合问题优先级为incomplete → needs_clarification → insufficient_evidence → out_of_scope → answered；保留各分项结果、缺口与执行问题。

## Agent与会话要求

由模型选择检索、读取或结束；程序执行工具后将真实观察交回模型，由模型调整下一步。每次响应只选择一个动作。最多8次模型决策、6次工具调用，结束及修正计入模型预算，失败与恢复计入工具预算；第6次工具后未结束则立即停止。

每任务最多一次模型决定的工具故障恢复、一次独立的格式修正。默认单次模型超时60秒、任务总超时300秒。SQLite保存完整问答及Trace，支持重启续问和会话隔离。

短期记忆采用对象、关注事项、待澄清事项三字段锚点加近期完整问答。锚点保留讨论事项和消息来源，不保存可复用的企业答案。业务与记忆分别校验；记忆非法或任务无合法结束时停用旧锚点，保留合法业务结果与告警。

## 成功标准

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| A01 | 明确答案 | 正确给出报销材料并引用原文 |
| A02 | 文档冲突 | 读取30/15天双方、补查；无裁定依据则保留冲突并请求确认 |
| A03 | 资料外问题 | 区分资料未覆盖与范围外，不补造制度 |
| A04 | 改写问题 | 口语问题仍返回相同材料事实及有效引用 |
| A05 | 上下文追问 | 理解产品指代，本轮重新读取分辨率依据 |
| A06 | 工具失败 | 错误进入模型观察，至多恢复一次，持续失败明确未完成 |

六类真实场景各独立运行两次，并通过资料替换验证答案、引用和动作随原文改变。详细结果见[效果验证](03-evaluation.md)，完整约束见[能力规格](specs/grounded-qa.md)。

## 范围边界

交付方式为本机单进程HTTP服务。界面、线上部署、登录权限、多Agent、独立向量数据库、PDF解析、上传与热更新不在范围内。Reranker和统计对照实验未实现；优先完成核心链路、可靠性及可复制验证。
