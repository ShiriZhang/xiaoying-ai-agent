## 已发生的设计取舍

- 从宽泛公司资料查询目标，收敛为三个主题、12 个虚构文档条目，并用不同主题承担冲突、替代关系与追问验证。
- 将 Query Rewrite 加混合检索设为必交；接受一个生成模型加一个本地 embedding 模型的边界，Reranker 留作可选实验。
- 为按会话编号续问选择服务端最小会话与 SQLite，同时保持 Agent 执行层职责清楚。
- 经过全量历史、普通窗口、锚点与摘要策略比较，选择三个结构化对话锚点加估算 token 历史窗口，避免把企业答案存成可直接复用的记忆。
- 为控制工作量，委托纯工程细节在实施中验证，明确排除界面、部署、多 Agent、权限与通用摘要等扩展。
